# FingerFury

Endless scrolling touch typing game.

![Screenshot of FingerFury](screenshot.png)


## Setup

Run `npm install` to load dependencies from npm.
Open `index.html` in your browser and press <kbd>enter</kbd> to start the game.


## Alternatives

- [GitType](https://github.com/unhappychoice/gittype) -
    CLI typing game that turns source code
    (any local or GitHub repository) into typing challenges.
